# 新项目确立！！！

今天我和阿兰准备开始一个新的项目，目前命名为 proDesk。

这个名字的意思是 productivity desktop，意为生产力桌面。

这个 app 的愿景呢是做一个更高效简洁方便的计划工具，来提升我们的规划和效率。

# 核心想法

我对这个 app 的核心想法是，我们在生活中会有各种各样的 deadline， 若我们能根据 deadline 设立项目，方便的规划项目工作的进程就能系统的计划任务的进度。

以这个体系去追踪进展是一个非常不错的确保计划能持续推进的手段！

# 设计核心

对了，我们还有一个愿望就是利用 Java 来实现这个软件。我以前在 software engineer 的课上有与小组参与相似项目的经历，但是并没有个人独立开发过类似的产品。

所以，我想借此机会，练习在此环境下搭建软件的经验。

经过筛选，我们找到了以下这个资源，去搭建我们的软件：

https://www.youtube.com/watch?v=Nv2DERaMx-4

希望我们能成功咯！
